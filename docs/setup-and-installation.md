# Setup and Installation

## Prerequisites

| Tool | Version | Purpose |
|------|---------|---------|
| Node.js | 16+ (recommend 18+) | JavaScript runtime |
| npm | 8+ (comes with Node.js) | Package manager |
| Git | 2+ | Version control |

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/IDS-Farah/ishraq-admin-panel.git
cd ishraq-admin-panel
```

### 2. Install Dependencies

```bash
npm install
```

This installs all packages listed in `package.json`, including:
- React 19, React Router DOM v7
- Tailwind CSS, Axios, Recharts, Lucide React
- React Hot Toast, XLSX, Day.js
- Testing library (@testing-library/react, jest-dom)

### 3. Configure Environment Variables

Copy or review the `.env` file:

```env
DISABLE_ESLINT_PLUGIN=true
REACT_APP_API_BASE_URL=https://localhost:44367/api
# REACT_APP_API_BASE_URL=/api
```

- `REACT_APP_API_BASE_URL`: Backend API base URL. Defaults to `https://localhost:44367/api`.
- For local development with a backend on a different port, update this value.
- The commented-out value `/api` can be used for same-origin proxy setups.

### 4. Backend Setup

**Note**: This repository contains only the frontend. A backend API must be running at the configured `REACT_APP_API_BASE_URL`.

Ensure the backend is accessible at `https://localhost:44367/api` (or your configured URL).

## Running the Application

### Development Mode

```bash
npm start
# or
npm run dev
```

- Starts the development server at `http://localhost:3000`
- Hot reload enabled: changes to source files trigger automatic refresh
- Lint errors shown in console

### Production Build

```bash
npm run build
```

- Builds the app for production to the `build/` folder
- Bundles React in production mode
- Minifies output with hashed filenames
- Build output is ready for static hosting

### Running Tests

```bash
npm test
```

- Launches the test runner in interactive watch mode
- Uses Jest with `@testing-library/react` and `@testing-library/jest-dom`
- Test files: `App.test.js`, `setupTests.js`

### Eject (Not Recommended)

```bash
npm run eject
```

- One-way operation that copies all build configuration (webpack, Babel, ESLint) into the project
- Not recommended unless you need full control over build tooling

## Verifying Installation

After `npm install` and `npm start`, you should see:

1. The development server starts on `http://localhost:3000`
2. The login page loads at `/login`
3. You can select a role (Admin / Employer / Job Seeker) and attempt login
4. The browser console shows no critical errors

## Troubleshooting Common Setup Errors

| Error | Cause | Solution |
|-------|-------|----------|
| `npm install` fails | Network issue, corrupted cache | Delete `node_modules` and `package-lock.json`, run `npm install` again |
| Port 3000 already in use | Another app running on port 3000 | Set `PORT=3001` before `npm start`, or stop the other app |
| Build fails | Missing dependencies, syntax error | Run `npm install` to ensure all deps are present; check console for error details |
| API calls fail | Backend not running, wrong URL | Verify backend is running at `REACT_APP_API_BASE_URL`; check `.env` |
| Blank white screen | JavaScript error, React crash | Check browser console for errors; verify all imports resolve |
| Tailwind styles not applied | CSS not loaded, build cache | Stop dev server, delete `node_modules/.cache`, restart |
