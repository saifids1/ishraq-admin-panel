# Project Documentation

This folder contains comprehensive documentation for the **ishraq-admin-panel** — a React-based administrative frontend for the Ishraq HR recruitment portal.

## Documentation Structure

| File | Description |
|------|-------------|
| [project-overview.md](./project-overview.md) | Project purpose, business problem, target users, technology stack |
| [requirements-and-features.md](./requirements-and-features.md) | Module-by-module features, business rules, permissions |
| [system-architecture.md](./system-architecture.md) | Architecture, data flow, Mermaid diagrams |
| [folder-structure.md](./folder-structure.md) | Directory and file layout with responsibilities |
| [frontend-documentation.md](./frontend-documentation.md) | React setup, routing, pages, components, state management |
| [backend-documentation.md](./backend-documentation.md) | Backend integration notes (frontend-only repo) |
| [api-documentation.md](./api-documentation.md) | API reference: endpoints, methods, payloads, responses |
| [database-documentation.md](./database-documentation.md) | Database notes (no database in this frontend repo) |
| [authentication-and-authorization.md](./authentication-and-authorization.md) | Auth flow, roles, protected routes |
| [business-workflows.md](./business-workflows.md) | End-to-end workflows with Mermaid diagrams |
| [setup-and-installation.md](./setup-and-installation.md) | Prerequisites, installation, running the app |
| [environment-configuration.md](./environment-configuration.md) | Environment variables and configuration |
| [testing-and-troubleshooting.md](./testing-and-troubleshooting.md) | Test commands, linting, known issues |
| [deployment-guide.md](./deployment-guide.md) | Build and deployment process |

## How to Use This Documentation

- New developers should start with [project-overview.md](./project-overview.md) and [setup-and-installation.md](./setup-and-installation.md).
- For API integration details, see [api-documentation.md](./api-documentation.md).
- For role-based access control, see [authentication-and-authorization.md](./authentication-and-authorization.md).
- For deployment, see [deployment-guide.md](./deployment-guide.md).
